    How it works

    Each new message from the support form is emailed to Send messages to, with the player's address as the reply-to, so you can answer straight from your mail app. Messages also stay here, even when email is off.

    Only port 465 works here: the server that sends these emails can't use ports 25 or 587.

    Gmail

    Mail server smtp.gmail.com. Username and from address: your Gmail address. Password: an app password (Google Account → Security → 2-Step Verification → App passwords), not your normal password.

    Other services with port 465 include Yahoo, Zoho, Amazon SES, SendGrid, Brevo, Mailgun and Resend. Outlook.com and iCloud Mail only offer port 587.

    The password is stored encrypted and is never shown again, here or anywhere else.
